# Black Knight Repository

A small Kodi add-on repository for the Black Knight (BKA) video add-on.

## Install on a Fire Stick or Kodi box

1. In Kodi, open **Settings → File manager → Add source**.
   Use this address and name it `bka-repo`:

   `https://smrrider.github.io/repository.blackknight/`

2. Go to **Add-ons → Install from zip file**. Allow unknown sources if Kodi asks.
   Open `bka-repo` and install `repository.blackknight-1.0.0.zip`.

3. Then **Add-ons → Install from repository → Black Knight Repository → Video add-ons → Black Knight**.

4. Open Black Knight **Settings**. Enter a TMDB API key, use **Connect Real-Debrid account**,
   and (for watchlist/scrobble) enter a Trakt app Client ID and Secret, then Connect Trakt.

Direct zip URL (Downloader, etc.):

`https://smrrider.github.io/repository.blackknight/zips/repository.blackknight/repository.blackknight-1.0.0.zip`

After the repository is installed, Kodi will offer Black Knight updates when a new version is published here.

Current add-on: Black Knight 2.7.1.
