Black Knight Repository

Install this repository in Kodi once. After that, Black Knight updates itself when a new zip is published here.

Install on a Fire Stick or Kodi box

  1. In Kodi, open Settings → File manager → Add source. Use this address and name it bka-repo:

https://smrrider.github.io/repository.blackknight/

  1. Go to Add-ons → Install from zip file. Allow unknown sources if Kodi asks. Open bka-repo and install:

repository.blackknight-1.0.0.zip

  1. Then Add-ons → Install from repository → Black Knight Repository → Video add-ons → Black Knight.
  2. Open Black Knight Settings. Enter a TMDB API key, use Connect Real-Debrid account, and (for watchlist/scrobble) enter a Trakt app Client ID and Secret, then Connect Trakt.

Direct zip URL (Downloader, etc.):

https://smrrider.github.io/repository.blackknight/zips/repository.blackknight/repository.blackknight-1.0.0.zip
